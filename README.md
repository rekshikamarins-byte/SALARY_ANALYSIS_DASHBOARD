# Employee Salary & Workforce Dashboard

## Project Overview

This project is an interactive **Power BI dashboard** created to analyze employee information, salary, compensation, bonuses, experience, departments, and employee performance.

The dashboard helps users understand workforce data through interactive charts, KPI cards, slicers, and detailed employee information.

## Data Source

The data was prepared in **Microsoft Excel** and imported into Power BI.

The dataset contains employee-related information such as:

* Employee ID
* Employee Name
* Department
* Designation
* Gender
* Location
* Date of Joining
* Experience
* Monthly Salary
* Annual CTC
* Bonus
* Performance

## Dashboard Pages

### 1. Executive Overview

Provides a summary of the workforce using KPI cards and charts.

### 2. Salary & Compensation

Shows salary, annual CTC, bonus, experience, and designation-related analysis.

### 3. Employee & Performance

Provides employee-level information and performance-related analysis.

## Power BI Features Used

* KPI Cards
* Slicers
* Charts and Visualizations
* Data Model
* DAX Measures
* Date/Calendar Table
* Drill-through
* Tooltips
* Page Navigation
* Filters

## Objective

The main objective of this dashboard is to provide a clear and interactive view of employee and compensation data, helping users understand workforce patterns and salary-related information.
